# Graduation-Blonde-Themed-Audio-Visualizer
 made an audio visualizer based on the albums Graduation by Kanye West and Blonde by Frank Ocean. You can either use your microphone or load a song from your computer. The visualizer shows the sound as moving bars or a waveform. You can choose between a Frank Ocean or a Kanye West theme . I built it in Python using Pygame and a few audio libraries
